# Monorail

Monorail track mod for Space Engineers.

## Features

### Monorail track library
- Straight blocks in 5 sizes: 2.5m, 12.5m, 25m, 50m, 100m.
- S-Bends (sideways)
![Straight and S-Bends](/assets/images/Straight.png)
- Arcs, with different bank degrees: 0°, 8°, 16°, 24°, and appropriate transitions to each bank
![Arcs](/assets/images/Arcs.png)
![Banks](/assets/images/Banks.png)
- Ramps, and smooth ramp transitions:
    - All ramps have a (High) and (Low) version, which denotes where the center is, for ease of placement.
    - The blocks are otherwise identical.

![Ramp high/low](/assets/images/RampsHighLow.png)
- Suspensions and wheels: set of suspensions that work specially well with the monorail blocks
![Suspensions and wheels](/assets/images/Wheels.png)
- Turnout: split a track into 2

![Turnout demo](/assets/images/turnouts_demo.gif)

- Station: conveyored block with a special connector that allows rolling stock to connect from drive-train height.
